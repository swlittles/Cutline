# Cutline 0.4.1

Privacy update for the public release: all game profiles now start with empty player aliases. Enter your own on-screen names before enabling local HUD OCR. Existing locally saved scan preferences remain on your Mac.

Developer signing identity and GitHub publication destinations are configuration values, with no creator-specific defaults in the source. Historical personal identifiers have been removed from repository content and commit metadata.

The affected 0.4.0 download was withdrawn. This release retains the existing editing and automatic-clipping behavior; the new mobile composition and local branding Settings are being developed separately on dev.

Requires macOS 14 or later. Universal Apple silicon / Intel app, Developer ID signed and Apple-notarized. Local audio/motion/OCR clipping requires no paid AI API. Cutline remains an early development version without full CapCut parity.
